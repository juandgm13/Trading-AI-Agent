# Dashboard

The Streamlit dashboard is launched from the Tkinter launcher via **Open dashboard**, or directly with:

```bash
streamlit run ui/app.py
```

All pages display a banner indicating whether the system is operating in **paper** or **live** mode (read from `ALPACA_BASE_URL`).

## Pages

### Summary (`ui/app.py`)
Main overview page:
- **Global market context** — latest `MarketContextAgent` report: sentiment, risk appetite, confidence, dominant themes, macro risks, and summary paragraph.
- **Symbol states** — metrics for how many symbols are in WATCHING / OPPORTUNITY_FOUND / POSITION_OPEN, table of open positions with target/stop-loss, list of symbols under active opportunity monitoring.
- **Recent trades** — last 10 executed orders.

### 1 · Artículos (`ui/pages/1_Articulos.py`)
Table of news articles ingested by the news pipeline. Filters: scope, impact level, ticker.

**Click any row** to open a modal with the full article detail: title, description, source, feed group, published date, scope, ticker, exchange affected, impact, LLM reasoning, clickable URL, and expiry/saved timestamps.

Requires Streamlit ≥ 1.36.0 (uses `@st.dialog` and `st.dataframe` row selection).

### 2 · Precios (`ui/pages/2_Precios.py`)
Price history chart for a selected symbol, sourced from `price_snapshots`.

### 3 · Trades (`ui/pages/3_Trades.py`)
Full trade history with a calculated P&L column (matched buy→sell pairs per symbol), filterable by symbol.

### 4 · Portfolio (`ui/pages/4_Portfolio.py`)
Live Alpaca account data: equity, cash, and open positions with target/stop-loss values pulled from `symbol_states`.

### 5 · Watchlist (`ui/pages/5_Watchlist.py`)
View and manage the list of monitored symbols. Includes Alpaca asset metadata columns:
- **Exchange** — e.g. NASDAQ, NYSE
- **Marginable** — ✓ / ✗
- **Shortable** — ✓ / ✗

Add new symbols (ticker + optional company name) or deactivate existing ones. When credentials are present, the "Add" button validates the symbol against `GET /v2/assets/{symbol}` and populates exchange/marginable/shortable automatically. Invalid or non-tradable symbols are rejected with an error.

### 6 · Estados (`ui/pages/6_Estados.py`)
- State machine table for all symbols (state, last analysis, target, stop-loss, position details).
- Per-symbol agent report history: select a symbol from the dropdown to browse the full JSON output of each sub-agent call.
- **Evidence chart** — if the selected symbol has a `chart_path` stored in `symbol_states` and the PNG file exists on disk, the candlestick chart is displayed inline (above the reports) via `st.expander` + `st.image()`, providing traceability between the chart and the reports that generated it.

## Shared components (`ui/components.py`)

`trading_mode_banner()` — renders a blue info banner for paper mode or a red warning banner for live mode. Called at the top of every page.

## Public report site (GitHub Pages)

Separate from the Streamlit dashboard: the daily Claude report is published as a static site generated by
`claude_agent/build_site.py` into `docs/` (served by GitHub Pages from branch `Trading-Agent_Claude`, folder `/docs`).

| Page | Content |
|---|---|
| `index.html` | Latest report: thermometer, summary, recommendations with action badges (+ change vs previous report), recent reports |
| `informes/YYYY-MM-DD.html` | Full report with sticky table of contents, chart lightbox, previous/next navigation. In each idea the chart stays pinned under the top bar while its text scrolls (`.idea-chart`, `position: sticky`) and leaves with its section |
| `archivo.html` | All reports grouped by month |
| `aprende.html` | Didactic syllabus and concepts already explained, linked to their report |
| `historial.html` | Recommendations per asset across the last 10 reports (latest first); a changed action vs the previous report is outlined. The index also marks each recommendation with "antes: X" or "nueva" |

Light/dark theme (system preference + toggle), responsive layout and print styles live in `claude_agent/site/`.
